# Requirements

## Objective
Build a hackathon-ready AI operations and finance workflow platform with controlled meta-agent communication, explainable recommendations, confidence scoring, and human review guardrails.

## Core Capabilities
1. Create business tasks.
2. Assign tasks.
3. Analyze a task with AI agents.
4. Display risk, urgency, priority, next action, confidence, and guardrail outcome.
5. Store a transcript and handoff file for every agent session.
6. Provide a CLI communicator for agent-to-agent interaction.

## Non-Goals
- No real payments.
- No real banking or payroll data.
- No automated financial approvals.
- No proprietary employer data.
